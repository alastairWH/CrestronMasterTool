# Crestron Master Tool

A modern installer and downloader for Crestron software and firmware, featuring FTP login, file listing, and silent install capabilities.

## Features
- FTP login with credentials
- Browse and select files from FTP
- Download and silent install software
- Download firmware

## Getting Started
1. Open the solution in Visual Studio 2022 or later.
2. Build and run the project.
3. Enter your FTP credentials to begin.
